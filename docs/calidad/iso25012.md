# Evaluación de calidad de datos · ISO/IEC 25012

Medida el 2026-11-27 sobre `data/oro/panel_mensual.csv` (895 filas × 66 columnas) con `python -m calidad.metricas`. Valores completos en [`calidad/reportes/iso25012.json`](../../calidad/reportes/iso25012.json); se recalculan en cada push en la CI.

ISO/IEC 25012 define 15 características. Las **inherentes** dependen solo de los datos; las **dependientes del sistema** dependen de cómo el sistema los guarda y entrega.

| Característica | Tipo | Medida (definición operativa) | Valor | Calificación |
|---|---|---|---:|---|
| Exactitud | Inherente | Filas que cumplen reglas de dominio: mín ≤ media ≤ máx, precio mín ≤ máx, precios > 0, temperatura en [−10, 50] °C, mes 1–12 | 100 % | Cumple |
| Completitud | Inherente | Celdas no nulas en las 14 columnas obligatorias (claves, precio frecuente, conteos, linaje, fecha) | **100 %** | Cumple (umbral del Sello 95 %) |
| | | Completitud de la tabla completa (incluye clima y precios por kg, nulos por diseño) | 95.2 % | Informativo |
| | | Temperatura media disponible / precipitación disponible | 86.9 % / 49.5 % | Limitación de la estación NOAA |
| Consistencia | Inherente | Sin contradicciones: conteo de precio ≤ observaciones; `fecha_mes` = año/mes; referencias de linaje = observaciones agregadas | 100 % | Cumple |
| Credibilidad | Inherente | Filas cuyo origen es una fuente oficial verificable por linaje y hash | 100 % | Cumple |
| Actualidad | Inherente | Meses de atraso del último mes con precios respecto a la medición | 0 meses (precios: nov-2026) | Cumple para precios |

| Confidencialidad | Inherente y del sistema | Datos personales en Oro | 0 columnas | Cumple |

## Lectura crítica

- **Exactitud medida ≠ exactitud real.** Las reglas detectan valores imposibles, no cotizaciones mal capturadas por la fuente. Una prueba de exactitud contra la realidad requeriría comparar con una segunda fuente (por ejemplo, precios al consumidor de PROFECO), que el observatorio no tiene.
- **Defecto corregido el 2026-11-27:** antes de la corrección, la integración de capturas de catálogo agregó 1,024 filas que mezclaban productos distintos en una variante "Todos". Las medidas de esta tabla no lo habrían detectado (las filas cumplían rangos y tenían linaje). Lección: falta una regla de **consistencia semántica** ("una fila de Oro corresponde a un solo producto"); se agregó como prueba de regresión.
- **Actualidad del clima** es la característica más débil y la que más afecta las conclusiones climáticas.
